Cap. 2. Unitatea de învățare: Cum funcționează Obiectele (Constructori și Destructori)

Pe înțelesul tuturor: Cum se creează, cum se folosesc și cum se șterg obiectele din memorie în programare.

De ce avem nevoie de constructori? Când creăm o variabilă simplă (cum ar fi un număr: int x = 10;), îi putem da o valoare direct. Dar când creăm un obiect complex (care are mai multe reguli și date în el), nu îi putem pune valori la întâmplare. Avem nevoie de o funcție specială numită constructor care să pregătească obiectul și să îi dea valorile de pornire corecte.

A) Tipurile de Constructori

Un constructor este o funcție din interiorul clasei care se execută automat fix în momentul în care creăm un obiect. Are două reguli simple de scris: poartă exact același nume cu clasa și nu are niciun tip returnat (nu scriem int, void sau altceva înaintea lui).

O clasă poate avea mai mulți constructori (acest lucru se numește supraîncărcare), împărțiți în trei categorii:

Tip Constructor Ce face mai exact? Regulă importantă
Implicit (fără parametri) Nu primește nicio informație (parantezele sunt goale). Pune valori de bază (cum ar fi 0 sau text gol) în interiorul obiectului. Dacă programatorul nu scrie niciun constructor, calculatorul îl creează singur pe acesta. Dar dacă programatorul scrie un alt constructor, cel automat dispare.
Cu parametri Primește date din exterior atunci când creăm obiectul, pentru a-l configura direct cu ce avem nevoie. Parametrii pot avea valori implicite (adică predefinite), ca să nu fim obligați să le completăm mereu.
De copiere Creează un obiect NOU luând ca model un obiect care există deja. Face practic o clonă. Se folosește când trimitem un obiect ca parametru într-o funcție sau când o funcție ne returnează un obiect.

B) Diferența dintre a Copia și a Atribui un obiect

Este foarte important să nu încurcăm constructorul de copiere cu operația de atribuire (asignare), pentru că în memorie lucrurile se întâmplă complet diferit:

  • Copierea Reală (Constructorul de copiere): Se folosește când creăm un obiect nou-nouț pe baza unuia vechi. Calculatorul alocă un spațiu de memorie complet separat pentru noul obiect și mută datele acolo. Dacă modificăm noul obiect, cel vechi rămâne intact.
  • Atribuirea (Ex: obiect1 = obiect2): Se folosește când ambele obiecte există deja. Aici nu se creează nimic nou, ci se face o copiere de referință. Asta înseamnă că ambele nume vor arăta spre același loc din memorie. Dacă modifici ceva în obiect1, se va schimba automat și în obiect2, pentru că ele împart aceeași memorie.

C) Destructorul (Cum se șterg obiectele)

Dacă constructorul se ocupă de „nașterea” obiectului, destructorul se ocupă de „moartea” lui. Este o funcție specială care are numele clasei, dar este precedată de semnul tildă (~). El curăță memoria și resurselor folosite de obiect înainte ca acesta să dispară.

Regulile lui sunt foarte stricte:

  • Se apelează singur (automat) atunci când programul termină treaba cu acel obiect.
  • Există un singur destructor per clasă. Nu poate primi parametri și nu returnează nimic.
  • Ordinea inversă: Obiectele se șterg în ordine inversă față de cum au fost create (ultimul obiect creat va fi primul șters).

D) La ce ne ajută cuvântul cheie 'this'?

Cuvântul cheie this înseamnă pur și simplu „obiectul curent”. Calculatorul îl folosește în două situații principale:

  1. Când numele coincid: Dacă un parametru din constructor are același nume cu un atribut din clasă, folosim this ca să arătăm care este al obiectului. (Exemplu: this.varsta = varsta; înseamnă că vârsta obiectului primește valoarea din parametrul vârstă).
  2. Pentru apeluri în lanț: Permite unei funcții să returneze textul return this;, ceea ce ne lasă să legăm mai multe comenzi una după alta pe o singură linie de cod.

E) Exemplu Practic: Clasa Array (Gestionarea unui Vector)

Următorul exemplu arată cum folosim constructorii, destructorul și pe this într-o clasă care gestionează un vector (o listă de numere):

class Array {
    private int[] t; // Vectorul nostru de numere
    private int c;   // Capacitatea (câte numere încap în el)

    // 1. Constructorul cu parametri (Creează vectorul cu dimensiunea cerută)
    public Array(int k) {
        this.c = k;          // Folosim 'this' pentru a nu încurca variabilele
        this.t = new int[c]; // Alocăm spațiu în memorie
    }

    // 2. Constructorul de copiere (Face o clonă reală într-un spațiu nou)
    public Array(Array other) {
        this.c = other.c;    // Luăm dimensiunea de la celălalt vector
        this.t = new int[c]; // CRITIC: Alocăm spațiu NOU în memorie ca să fie independenți!
        
        // Copiem numerele unul câte unul
        for (int i = 0; i < this.c; i++) {
            this.t[i] = other.t[i];
        }
    }

    // 3. Destructorul (Anunță când vectorul este șters)
    ~Array() {
        Console.WriteLine("Obiectul a fost șters din memorie, iar resursele au fost eliberate.");
    }
}

De ce a fost important constructorul de copiere aici? Dacă nu îl scriam și făceam o simplă atribuire (vector1 = vector2), amândouă ar fi folosit același tabel de numere din memorie. Când s-ar fi modificat un număr în vector1, s-ar fi stricat automat și în vector2. Datorită constructorului de copiere de mai sus, fiecare are tabelul lui separat și funcționează independent, fără erori.

Cap. 3 Rezolvarea problemei algoritmice

Enunț Problemă: Într-o pușculiță se află $N$ monede de diferite valori cu greutatea totală $G$ grame. Greutatea fiecărei monede de o anumită valoare este dată în tabelul ce urmează. Elaborați un program care determină suma minimă $S$ care ar putea să fie în pușculiță.
Valoarea monedei (lei) Greutatea monedei (grame)
11
52
103
254
505

Implementarea optimizată în limbajul C++

#include <iostream>
#include <climits>
using namespace std;

int tool(int coin){
    if (coin==1) return 1;
    if (coin==2) return 5;
    if (coin==3) return 10;
    if (coin==4) return 25;
    if (coin==5) return 50;
}

int minCoins(int coins[], int m, int V)
{
    if (V == 0) return 0;
    int res = INT_MAX;
    for (int i=0; i<m; i++)
    {
        if (tool(coins[i]) <= V)
        {
            int sub_res = minCoins(coins, m, V-tool(coins[i]));
            if (sub_res != INT_MAX && sub_res + 1 < res)
                res = sub_res + 1;
        }
    }
    return res;
}

int main()
{
    int arr[100]; int S; int n;
    cout << " n= "; cin >> n; cout << endl;
    cout << " S= "; cin >> S; cout << endl;
    for(int i=0; i<n; i++)
        cin >> arr[i];
    cout << "suma minima de monede= " << minCoins(arr, n, S);
    cout << endl;
    return 0;
}

Rezultatul execuției și analiza

Programul determină corect, prin tehnica recursivității, numărul minim de monede necesare pentru a cumula suma cerută în funcție de maparea greutate-valoare introdusă de la tastatură, respectând complexitatea structurală impusă de enunț.
