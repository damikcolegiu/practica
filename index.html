Cap. 2. Unitatea de învățare: Cum funcționează Obiectele (Constructori și Destructori)

Conceptul general: Cum se creează, cum se copiază și cum se eliberează obiectele din memorie.

De ce avem nevoie de constructori? Când definim o variabilă simplă, îi putem atribui o valoare direct. În schimb, un obiect complex necesită reguli specifice de inițializare a stării sale interne. Constructorul este funcția responsabilă de alocarea corectă a resurselor și setarea stării inițiale sigure.

A) Tipurile de Constructori

Un constructor se execută automat la instanțierea unui obiect. Acesta poartă numele clasei și nu returnează niciun tip de date.

Tip Constructor Rol Funcțional Regulă de Bază
Implicit (fără parametri) Inițializează atributele obiectului cu valori predefinite de bază (0, null, etc.). Dacă nu este definit explicit niciun constructor, mediul de execuție îl generează automat. Dispare dacă adăugăm un constructor personalizat.
Cu parametri Configurează obiectul în mod direct utilizând date furnizate din exterior în momentul instanțierii. Permite utilizarea parametrilor impliciți pentru a evita obligativitatea completării tuturor argumentelor.
De copiere Creează o entitate nouă prin duplicarea stării unui obiect existent. Este esențial pentru a preveni partajarea accidentală a zonelor de memorie dinamică între obiecte distincte.

B) Diferența dintre Copiere și Atribuire

Este critic să diferențiem copierea la inițializare de operația de atribuire ulterioară:

  • Constructorul de copiere: Intervine exclusiv la crearea unui obiect nou. Acesta alocă un spațiu de memorie independent și duplică valorile obiectului sursă, garantând izolarea completă a celor două entități.
  • Operatorul de atribuire: Se aplică atunci când ambele entități sunt deja existente în memorie. În lipsa unei redefiniri clare, o simplă atribuire de referințe sau pointeri face ca ambele variabile să indice aceeași zonă de memorie, generând efecte secundare la modificarea uneia dintre ele.

C) Destructorul și Managementul Resurselor

Destructorul asigură eliberarea resurselor ocupate de un obiect atunci când ciclul său de viață se încheie. Esențial precedat de simbolul tildă (~).

  • Este invocat în mod automat de către sistem la ieșirea din domeniul de vizibilitate al obiectului.
  • O clasă are un singur destructor; acesta nu acceptă parametri și nu returnează valori.
  • Ordinea de distrugere: Obiectele locale dintr-un bloc sunt distruse în ordine inversă față de ordinea creării lor.

D) Utilitatea pointerului/referinței 'this'

Cuvântul cheie this reprezintă o referință directă către instanța curentă a obiectului:

  1. Rezolvarea conflictelor de nume: Diferențiază atributele clasei de parametrii constructorului atunci când aceștia poartă aceleași denumiri.
  2. Apeluri în lanț (Chaining): Permite returnarea instanței curente pentru a înlănțui succesiv execuția mai multor metode pe aceeași linie.

E) Exemplu Practic: Clasa Array

class Array {
    private int[] t;
    private int c;

    public Array(int k) {
        this.c = k;
        this.t = new int[c];
    }

    public Array(Array other) {
        this.c = other.c;
        this.t = new int[c];
        for (int i = 0; i < this.c; i++) {
            this.t[i] = other.t[i];
        }
    }

    ~Array() {
        System.out.println("Resursele alocate tabloului au fost eliberate din memorie.");
    }
}

Cap. 3 Rezolvarea problemelor algoritmice

Enunț Problemă: Într-o pușculiță se află N monede de diferite valori cu greutatea totală G grame. Greutatea fiecărei monede de o anumită valoare este dată în tabelul ce urmează. Elaborați un program care determină suma minimă S care ar putea să fie în pușculiță pentru greutatea totală dată G.
Valoarea monedei (lei) Greutatea monedei (grame)
11
52
103
254
505

Implementarea optimizată în limbajul C++ (Programare Dinamică)

#include <iostream>

using namespace std;

int main() {
    int v[] = {1, 5, 10, 25, 50};
    int w[] = {1, 2, 3, 4, 5};
    int n = 5;
    int G;

    if (!(cin >> G)) return 0;

    int dp[10005];
    dp[0] = 0;

    for (int i = 1; i <= G; i++) {
        dp[i] = 1e9;
    }

    for (int i = 0; i < n; i++) {
        for (int j = w[i]; j <= G; j++) {
            if (dp[j - w[i]] != 1e9) {
                if (dp[j - w[i]] + v[i] < dp[j]) {
                    dp[j] = dp[j - w[i]] + v[i];
                }
            }
        }
    }

    if (dp[G] == 1e9) {
        cout << -1 << endl;
    } else {
        cout << dp[G] << endl;
    }

    return 0;
}

Rezultatul execuției și analiza

Pentru a evita apelurile recursive redundante care ar bloca execuția, algoritmul folosește Programarea Dinamică. Tabloul unidimensional dp stochează sumele minime posibile pentru fiecare sub-greutate de la 0 la G. Complexitatea de timp este redusă la O(N * G), oferind un răspuns instantaneu chiar și pentru valori ridicate ale greutății totale.
